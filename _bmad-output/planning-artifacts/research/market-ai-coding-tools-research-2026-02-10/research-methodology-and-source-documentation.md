# Research Methodology and Source Documentation

## Research Approach

This market research was conducted on **2026-02-10** using a comprehensive multi-method approach:

**Data Collection Methods:**
- Live web search across 50+ queries with source verification
- Parallel research agents for competitive deep-dives (10 agents for competitor profiling)
- Cross-referencing multiple independent sources for critical claims
- Review of industry reports, developer surveys, and company announcements

**Primary Sources:**
- [Stack Overflow 2025 Developer Survey](https://survey.stackoverflow.co/2025/ai) -- largest annual developer survey
- [JetBrains State of Developer Ecosystem 2025](https://blog.jetbrains.com/research/2025/10/state-of-developer-ecosystem-2025/) -- comprehensive developer tool usage data
- [Anthropic 2026 Agentic Coding Trends Report](https://resources.anthropic.com/hubfs/2026%20Agentic%20Coding%20Trends%20Report.pdf) -- industry-leading AI coding analysis
- [Qodo State of AI Code Quality](https://www.qodo.ai/reports/state-of-ai-code-quality/) -- quantitative code quality analysis
- [METR Study](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/) -- randomised controlled trial of AI tool productivity

**Secondary Sources:**
- TechCrunch, CNBC, Forbes for funding and valuation data
- Martin Fowler, Addy Osmani, Thoughtworks for technical analysis
- Grand View Research, Mordor Intelligence, MarketsAndMarkets for market sizing
- GitHub, Reddit, HackerNews for community sentiment
- Company blogs and documentation for product details

## Research Quality Assessment

| Dimension | Assessment | Notes |
|-----------|-----------|-------|
| Source diversity | Strong | 40+ independent sources across industry reports, surveys, news, and community |
| Data currency | Strong | All data from 2025-2026, verified against live sources |
| Quantitative evidence | Strong | Multiple quantitative studies (METR, Qodo, Stack Overflow) |
| Qualitative evidence | Strong | Community sentiment, expert analysis, practitioner testimony |
| Geographic coverage | Good | Primarily US/global, some Asia-Pacific and European data |
| Confidence calibration | Explicit | All uncertain claims tagged with confidence levels |

## Research Limitations

1. **Market sizing estimates vary significantly** between research firms (e.g., $7.37B vs $29.47B for 2025 depending on category definition). We used the more conservative estimates.
2. **Revenue data for private companies** is based on reported figures and analyst estimates, not verified financials.
3. **Community sentiment** can shift rapidly. Reddit/HN discussions represent a snapshot, not a permanent state.
4. **Predictive claims** (market forecasts, adoption rates) carry inherent uncertainty. We tagged confidence levels throughout.
5. **Solo founder perspective** may introduce confirmation bias toward opportunities that favour small teams. We actively searched for counter-evidence.
